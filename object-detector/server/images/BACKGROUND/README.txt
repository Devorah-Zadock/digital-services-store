תיקייה זו לא חובה, אבל מומלצת מאוד.
שים כאן תמונות "ריקות" - רקעים בלי אף אחד מהאובייקטים שרוצים
לזהות (למשל: שמיים, קיר, כביש ריק, דשא בלי כלום, רצפה וכו').
זה מלמד את המודל להבדיל בין "יש כאן אובייקט" לבין "זה סתם רקע",
ומצמצם משמעותית זיהויי-שווא.

שם התיקייה הזו (BACKGROUND) הוא מיוחד - הגדרות המערכת (config.py,
משתנה BACKGROUND_LABELS) מזהות אותו ולא מציגות אותו כ"אובייקט"
בתוצאה הסופית, גם אם המודל מסווג חלון כלשהו לקטגוריה הזו.
