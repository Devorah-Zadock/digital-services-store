# BizKit — אתר מכירת תבניות עסקיות

אתר סטטי (HTML/CSS/JS בלבד, ללא בקאנד) למכירת תבניות עסקיות מוכנות — קורות חיים, מצגות עסקיות ובהמשך גם מדריכי אוטומציה חינמיים ל-Make.

## מבנה הפרויקט

```
index.html               בית
products.html             קטלוג המוצרים
product-cv-modern.html    עמוד מוצר: תבנית קורות חיים
product-biz-deck.html     עמוד מוצר: תבנית מצגת עסקית
about.html                אודות
contact.html               צור קשר
css/style.css              עיצוב האתר (משתני צבע במעלה הקובץ)
js/main.js                  תפריט מובייל + טופס יצירת קשר
images/previews/            תמונות תצוגה מקדימה של המוצרים
```

## הרצה מקומית

אין תלות בשום כלי בנייה — פותחים את `index.html` בדפדפן, או מריצים שרת סטטי פשוט:

```bash
python3 -m http.server 8000
```

## פריסה (Deploy)

אתר סטטי טהור — אפשר לפרוס בחינם ב-GitHub Pages, Netlify או Vercel, פשוט על ידי חיבור הריפו.

## חשוב לפני שהאתר עולה לאוויר: חיבור תשלומים

**קבצי המוצר האמיתיים (docx/pptx) לא נמצאים בריפו הזה** — הם נשלחו אליך ישירות. יש להעלות אותם לפלטפורמת מכירה כמו Gumroad / Payhip / Lemon Squeezy, וליצור שם מוצר לכל תבנית עם קישור לתשלום.

בקבצים הבאים יש placeholder לכפתור הרכישה, מסומן בהערת `TODO`:

- `product-cv-modern.html` — כפתור "לרכישה מאובטחת"
- `product-biz-deck.html` — כפתור "לרכישה מאובטחת"

יש להחליף את ה-`href` בקישור התשלום האמיתי מהפלטפורמה שבחרת.
