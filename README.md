# BizKit — אתר מכירת תבניות עסקיות

אתר סטטי (HTML/CSS/JS בלבד, ללא בקאנד) לתבניות עסקיות מוכנות — קורות חיים מותאמים אישית (עברית/אנגלית), מצגות עסקיות, גיליונות Excel, ובהמשך גם מדריכי אוטומציה חינמיים ל-Make.

## מבנה הפרויקט

```
index.html                בית
products.html              קטלוג המוצרים (מסונן לפי קטגוריה, נבנה מ-js/products-data.js)
product.html                עמוד מוצר גנרי — קורא ?slug= ומציג את הפרטים מתוך products-data.js
builder.html                 בילדר קורות חיים חי: עברית/אנגלית, עריכה + תצוגה מקדימה + הורדת PDF חינמית, עם שדרוג Pro אופציונלי
about.html                 אודות
contact.html                צור קשר
downloads/                   קבצי המצגות והגיליונות החינמיים (הורדה ישירה, בלי Gumroad)
css/style.css               עיצוב כללי של האתר (משתני צבע במעלה הקובץ)
css/builder.css              עיצוב ייעודי לעמוד הבילדר + מדיה של הדפסה
js/products-data.js           מקור האמת לכל המוצרים בקטלוג
js/catalog.js                 רינדור הקטלוג, הפילטרים ועמוד המוצר הגנרי
js/cv-content.js              תוכן ברירת מחדל (עברית + אנגלית) לכל תבנית קו"ח
js/cv-render.js               רינדור קורות החיים ל-HTML — תומך RTL/LTR, משותף לתצוגה ולהדפסה
js/color-utils.js             גזירת פלטת צבעים מלאה מצבע ראשי אחד שהמשתמש בוחר
js/builder.js                  לוגיקת הבילדר: טופס חי, מעבר שפה, אימות רישוי מול Gumroad, ייצוא PDF
js/main.js                    תפריט מובייל + טופס יצירת קשר
images/previews/               תמונות תצוגה מקדימה של המוצרים בקטלוג
```

## הרצה מקומית

אין תלות בשום כלי בנייה — פותחים את `index.html` בדפדפן, או מריצים שרת סטטי פשוט:

```bash
python3 -m http.server 8000
```

## פריסה (Deploy)

אתר סטטי טהור — אפשר לפרוס בחינם ב-GitHub Pages, Netlify או Vercel, פשוט על ידי חיבור הריפו.

## הקטלוג

- **קורות חיים (15 תבניות, 4 קטגוריות מקצועיות)** — תכנות, עיצוב, הנהלת חשבונות, כללי/עסקי. כל תבנית ניתנת לעריכה בעברית **או אנגלית** (מחליפים בטאב בבילדר — הכיוון של כל הפריסה מתהפך אוטומטית ל-LTR באנגלית), כולל תמיכה בסעיף "פרויקטים" אופציונלי (רלוונטי בעיקר לתבניות תכנות).
- **מצגות (5 תבניות)** — פרופיל חברה, הצגת מוצר, תוכן/וובינר, פיץ' למשקיעים, פורטפוליו יצירתי. **חינמיות לגמרי**, קובץ PowerPoint מלא להורדה ישירה מ-`downloads/`.
- **גיליונות Excel (2 תבניות)** — תקציב חודשי אישי, חשבונית עסקית. **חינמיות**, עם נוסחאות אמיתיות (SUM/SUMIF) לא מספרים קבועים.

## איך זה עובד: קורות חיים מול הכול השאר

- **קורות חיים** נערכים **בבילדר החי** (`builder.html`) — המשתמש ממלא את הפרטים שלו, בוחר שפה וצבע, ורואה תוצאה חיה. **הורדת PDF חינמית תמיד**, עם שורת קרדיט קטנה בתחתית ("Made with BizKit"). כך כל PDF שיוצא הוא מסמך אישי וממוסה, לא תבנית גנרית שאפשר להעביר הלאה כקובץ עריכה.
- **מצגות וגיליונות Excel** נמכרות/ניתנות כקובץ **מלא להורדה ישירה** — כי אלה מסמכים שממשיכים לערוך לאורך זמן (מוסיפים שקפים, מעדכנים תקציב), ולכן אין טעם לנעול אותם מאחורי בילדר.

## BizKit Pro — מה זה בפועל

שדרוג חד-פעמי אחד שנותן:
1. **הסרת שורת הקרדיט** מהורדות ה-PDF של קורות החיים, בכל התבניות, לתמיד.
2. **גישה מוקדמת** לכל תבנית קו"ח חדשה שתתווסף בעתיד, לפני שהיא יוצאת לציבור.

זה כל מה שהוא — לא צריך "לרכוש" כדי להשתמש בבילדר או להוריד PDF; זה שדרוג נחמד-להיות-לו, לא שער כניסה.

## חשוב לפני שהאתר עולה לאוויר: חיבור Gumroad ל-BizKit Pro

מוצר **אחד בלבד** ב-Gumroad מספיק (לא צריך מוצר נפרד לכל תבנית, ולא צריך שום דבר בשביל המצגות/הגיליונות — אלה קבצים חופשיים לגמרי):

1. יוצרים מוצר בשם "BizKit Pro" (אפשר "מוצר דמה" בלי קובץ מצורף — הבילדר עצמו מייצר את ה-PDF, לא Gumroad).
2. בהגדרות המוצר מפעילים **"Generate a unique license key per sale"** (זה מה שמאפשר לבילדר לאמת רכישה בלי שרת משלכם).
3. מעתיקים את ה-**permalink** של המוצר (החלק שאחרי `gumroad.com/l/` בקישור המוצר).
4. פותחים את `js/builder.js` ובאובייקט `GUMROAD_PRODUCT` שבראש הקובץ ממלאים:
   - `permalink`: ה-permalink שהעתקתם
   - `checkoutUrl`: קישור הרכישה המלא (`https://gum.co/...` או `https://<שם-החנות>.gumroad.com/l/<permalink>`)

עד שזה לא מוגדר, כפתור "שדרוג ל-Pro" בבילדר מציג הודעת "בקרוב" במקום לנווט לקישור שבור.

זהו — אין צורך בשרת נוסף. הבילדר קורא ל-Gumroad License Verification API (`api.gumroad.com/v2/licenses/verify`) ישירות מהדפדפן, ושומר את מצב הפתיחה ב-localStorage של הדפדפן (כלומר פתוח על אותו מכשיר/דפדפן שבו הוזן הקוד).

### הערה חשובה על רמת ההגנה

האימות מול Gumroad מונע **שיתוף מקרי** — אבל זו לא הגנת DRM אמיתית: משתמש טכני שמכיר את כלי הפיתוח של הדפדפן יכול תיאורטית לעקוף את הנעילה בצד הלקוח. זו בדיוק אותה רמת הגנה שיש בפועל בכל אתר תבניות סטטי בלי שרת — כדי להגיע להגנה אמיתית יידרש רכיב שרת קטן (Cloudflare Worker / Vercel Function), שאפשר להוסיף בהמשך אם זה יהפוך לבעיה אמיתית.

## הערה על קובצי ה-Excel

נוסחאות ה-SUM/SUMIF בשני הגיליונות נבדקו ידנית (חישוב על הנייר מול מה שהנוסחה אמורה להחזיר), אבל לא עברו הרצת אימות אוטומטית בסביבת הפיתוח — LibreOffice Calc לא מותקן בסביבה הזו. מומלץ לפתוח את שני הקבצים פעם אחת ב-Excel כדי לוודא שהסכומים מסתדרים לפני שמעלים אותם.
