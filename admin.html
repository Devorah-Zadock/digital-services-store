אזור ניהול

הכל כאן מחולק ללשוניות לפי נושא.

לחיצה על שורה פותחת פירוט מלא. לחיצה על ✕ ליד אתר או קורות חיים מוחקת אותם לצמיתות מהחשבון של הלקוח.

לקוחות ושימוש — עוד לא חובר

כדי לראות כאן כל משתמש שנרשם, באיזה כלים באתר הוא השתמש בפועל (איזו תבנית אתר, האם הוריד, האם השתמש בבניית קורות חיים), ולמחוק אתר/קו"ח שיוזר יצר — יש להריץ הגדרה חד-פעמית:

  1. ב-Supabase Dashboard → SQL Editor, מריצים את הקובץ supabase/sql/customer_profiles.sql מתוך הריפו — זה יוצר טבלת customer_profiles שמתמלאת אוטומטית בכל הרשמה חדשה.
  2. פורסים את הפונקציה supabase functions deploy admin-stats (או מדביקים את supabase/functions/admin-stats/index.ts ב-Dashboard → Edge Functions → New Function).
  3. ב-Dashboard → Edge Functions → admin-stats → Secrets, מוסיפים סוד בשם ADMIN_EMAILS עם כתובת המייל שאיתה נכנסים לאתר (אם יש כמה מנהלות — מפרידים בפסיקים, בלי רווחים).
  4. נכנסים לעמוד הזה (admin.html) כשמחוברים עם אותו חשבון — הגישה נבדקת מול השרת לפי מייל, לא מול סיסמה שכתובה בקוד.
  5. בנוסף, כדי לראות כאן גם שימוש בהצעות מחיר והורדות של מצגות/גליונות: ב-SQL Editor מריצים גם את supabase/sql/usage_events.sql מתוך הריפו (חד-פעמי, לא תלוי בשלבים הקודמים).
