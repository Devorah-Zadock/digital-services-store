אזור ניהול

הכל כאן מחולק ללשוניות לפי נושא.

איך מחברים את תיבת ההודעות

האתר סטטי (בלי שרת/מסד נתונים משלו) — לכן כדי שהודעות מבקרים יישמרו לצמיתות במקום פרטי שרק את רואה (ולא ייעלמו עם רענון או ייסגרו במחשב של המבקר), הן צריכות להישלח לשירות חיצוני קטן. זה כבר מחובר לטופס המשוב באתר — נשאר רק להפעיל אותו:

  1. נכנסים ל-formspree.io ופותחים חשבון חינמי (עד 50 הודעות בחודש, בלי כרטיס אשראי) עם digital.dz.studio@gmail.com.
  2. יוצרים טופס חדש (New Form) ומאשרים את כתובת המייל.
  3. מעתיקים את כתובת ה-endpoint (נראית כך: https://formspree.io/f/xxxxxxxx) ומדביקים אותה בקבוע FEEDBACK_ENDPOINT בקובץ js/widgets.js.
  4. באותו חשבון formspree יש לוח בקרה עם כל ההודעות שאי פעם נשלחו — מעתיקים את כתובת הקישור אליו ומדביקים בקבוע ADMIN_INBOX_URL בקובץ js/admin.js.

אחרי זה, כל הודעה שנשלחת דרך האתר גם מגיעה מייד למייל שלך וגם נשמרת בלוח הבקרה — קבועה, לא נמחקת, ונגישה רק לך דרך ההתחברות לחשבון ה-formspree שלך.

לחיצה על שורה פותחת פירוט מלא. לחיצה על ✕ ליד אתר או קורות חיים מוחקת אותם לצמיתות מהחשבון של הלקוח.

לקוחות ושימוש — עוד לא חובר

כדי לראות כאן כל משתמש שנרשם, באיזה כלים באתר הוא השתמש בפועל (איזו תבנית אתר, האם הוריד, האם השתמש בבניית קורות חיים), ולמחוק אתר/קו"ח שיוזר יצר — יש להריץ הגדרה חד-פעמית:

  1. ב-Supabase Dashboard → SQL Editor, מריצים את הקובץ supabase/sql/customer_profiles.sql מתוך הריפו — זה יוצר טבלת customer_profiles שמתמלאת אוטומטית בכל הרשמה חדשה.
  2. פורסים את הפונקציה supabase functions deploy admin-stats (או מדביקים את supabase/functions/admin-stats/index.ts ב-Dashboard → Edge Functions → New Function).
  3. ב-Dashboard → Edge Functions → admin-stats → Secrets, מוסיפים סוד בשם ADMIN_STATS_KEY עם כל מחרוזת שרוצים (למשל סיסמה אקראית).
  4. מדביקים את אותה מחרוזת בדיוק בקבוע ADMIN_STATS_KEY בקובץ js/admin.js.
  5. בנוסף, כדי לראות כאן גם שימוש בהצעות מחיר והורדות של מצגות/גליונות: ב-SQL Editor מריצים גם את supabase/sql/usage_events.sql מתוך הריפו (חד-פעמי, לא תלוי בשלבים הקודמים).
