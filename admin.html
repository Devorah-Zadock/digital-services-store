אין הרשאת גישה

החשבון שמחובר כרגע לא מוגדר כמנהל/ת האתר. אם זה החשבון שלך, ודאי שהמייל שלו נמצא ברשימת ADMIN_EMAILS ב-Supabase Dashboard → Edge Functions → admin-stats → Secrets.

חזרה לעמוד הבית

אזור ניהול

DeskKit · ניהול לקוחות, הודעות והרשאות

אזור הניהול — עוד לא חובר

  1. ב-Supabase Dashboard → SQL Editor, מריצים את supabase/sql/customer_profiles.sql.
  2. פורסים את הפונקציה admin-stats (Dashboard → Edge Functions).
  3. ב-Edge Functions → admin-stats → Secrets מוסיפים ADMIN_EMAILS עם המייל שלך (כמה מיילים — מופרדים בפסיקים).

צריך להריץ עדכון חד-פעמי למסד הנתונים

תצוגת הלקוחות החדשה (חיפוש, סינון ודפדוף בצד השרת, מספרי לקוח קבועים, יומן ניהול והרשאות) צריכה את הקובץ supabase/sql/admin_dashboard.sql.

  1. Supabase Dashboard → SQL Editor → מדביקים את כל הקובץ → Run.
  2. פורסים מחדש את הפונקציה admin-stats.
  3. מרעננים את העמוד.

הודעה חדשה

רשימת העדכונים

—

נמענים פעילים: חשבונות מאושרים, לא מושעים, שלא הסירו את עצמם. כל מייל כולל קישור הסרה בלחיצה אחת.

עד 50 מיילי דיוור ביום (מתוך 100 של המסלול החינמי) — השאר שמור תמיד למיילי הרשמה, איפוס סיסמה וברוכים הבאים. כשמגיעים לתקרה השליחה נעצרת, ולחיצה על "המשך שליחה" למחרת ממשיכה בדיוק מאיפה שנעצרה. אף אחד לא יקבל את אותה הודעה פעמיים.
